# UI Test Cases — Iteration 2
## 1. Депозит денег пользователем
## Требования:
- Максимальная сумма депозита 5000

### DEP-01. Успешное пополнение выбранного счета
Тип теста: Позитивный, интеграционный(UI-API)

Предусловия:
- Пользователь авторизован
- У пользователя есть счет ACC24
- Через API получен и сохранен текущий баланс счета ACC24

Тестовые данные:
- Счет: ACC24
- Сумма пополнения: 100 (не превышает максимальный лимит 5000)

Шаги выполнения:
1. Открыть страницу Deposit Money
2. В Select Account выбрать счет ACC24
3. В Enter Amount ввести сумму пополнения 100
4. Нажать кнопку Deposit
5. Проверить сообщение об успешном пополнении
6. Проверить обновленный баланс счета в UI
7. Отправить GET-запрос /api/v1/customer/accounts
8. Найти в ответе счет ACC24 и проверить его баланс

Ожидаемый результат:
Пополнение на сумму 100 успешно выполняется
- В UI отображается сообщение: Successfully deposited $100 to account ACC24!
- Баланс счета в UI увеличился на 100 относительно первоначального значения
- API возвращает HTTP-статус 200 OK
- Баланс счета ACC24 в ответе API увеличился на 100 относительного первоначального значения
- Балансы в UI и API совпадают

## 2. Перевод денег с одного аккаунта на другой
## Требования:
- Максимальная сумма перевода 10000

### TRF-01. Успешный перевод денег на другой счёт
Тип теста: Позитивный, интеграционный (UI–API)

Предусловия:
- Пользователь авторизован
- Существует счёт отправителя, доступный для выбора в поле Select Your Account
- Существует счёт получателя, на который разрешён перевод
- Известно имя владельца счёта получателя
- Через API получены и сохранены начальные балансы счетов отправителя и получателя

Тестовые данные:
- Счёт отправителя: ACC24
- Счёт получателя: существующий счёт другого пользователя
- Имя получателя: имя владельца счёта получателя
- Сумма перевода: 100

Шаги выполнения:
1. Открыть страницу Make a Transfer
2. В поле Select Your Account выбрать счёт ACC24
3. Ввести имя получателя в поле Recipient Name
4. Ввести номер счёта получателя в поле Recipient Account Number
5. Ввести сумму перевода 100 в поле Amount
6. Нажать на галочку Confirm details are correct
7. Нажать кнопку Send Transfer
8. Проверить результат операции в UI
9. Проверить обновлённые балансы обоих счетов в UI
10. Отправить GET-запрос /api/v1/customer/accounts и проверить балансы счетов в ответе

Ожидаемый результат:
- Перевод суммы 100 успешно выполняется
- В UI отображается сообщение об успешном переводе
- Баланс счёта отправителя уменьшается на 100 относительно первоначального значения
- Баланс счёта получателя увеличивается на 100 относительно первоначального значения
- API возвращает HTTP-статус 200 OK
- Балансы обоих счетов в API соответствуют ожидаемым изменениям
- Балансы, отображаемые в UI и возвращаемые API, совпадают

## 3. Изменение имени пользователя
## Требования:
- Имя профиля - два слова состоящее только из букв обязательно

### PROF-01. Успешное изменение имени профиля
Тип теста: Позитивный, интеграционный (UI–API)

Предусловия: 
- Пользователь авторизован
- Через API получено и сохранено текущее имя пользователя

Тестовые данные:
- Новое имя Kate Bark

Шаги выполнения:
1. Нажать на имя пользователя слева от значка Logout
2. Убедиться, что открылась страница Edit Profile
3. В поле Enter new name ввести Kate Bark
4. Нажать кнопку Save Changes
5. Проверить результат операции в UI
6. Проверить имя пользователя, отображаемое в интерфейсе
7. Отправить GET-запрос /api/v1/customer/profile
8. Проверить имя пользователя в ответе API

Ожидаемое результат:
- Имя Kate Bark успешно сохраняется
- В UI отображается сообщение об успешном изменении имени
- В интерфейсе отображается новое имя пользователя
- API возвращает HTTP-статус 200 OK
- В ответе API поле name содержит Kate Bark
